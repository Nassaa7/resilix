# Contributing to Resilix

Thank you for your interest in contributing to **Resilix**! We welcome contributions of all kinds: bug fixes, documentation improvements, new resilience patterns, and feature requests.

## Development Setup

1. **Fork and Clone**
   ```bash
   git clone https://github.com/Nassaa7/resilix.git
   cd resilix
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Tests**
   ```bash
   npm test
   ```

4. **Build the Package**
   ```bash
   npm run build
   ```

## Pull Request Guidelines

- Ensure all existing and new unit tests pass (`npm test`).
- Ensure TypeScript compiles with zero errors (`npm run lint`).
- Add tests for any new behavior or bug fixes.
- Keep commits descriptive and follow standard conventional commit conventions (e.g. `feat:`, `fix:`, `docs:`).

## Code of Conduct

Please be respectful and constructive in all interactions within issues, pull requests, and discussions.
